# Partner Portal

A modern, responsive web application for Partner Portal. Apply for loans in minutes and get funds in your account within 48 hours.

## Features
- **Secure Authentication**: OTP-based authentication flow.
- **Modern UI**: Vibrant orange & black gradient themes with a responsive split-panel layout.
- **Dynamic Interactions**: Animated marquees and hover states using Framer Motion.
- **Typography**: Clean and geometric Urbanist font.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React (Icons)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
